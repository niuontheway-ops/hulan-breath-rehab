壶兰呼吸康复工作台

此安装包用于需要使用本应用的医院工作电脑。

• 仅为当前 Windows 用户安装，默认无需管理员权限。
• 包含本地网页、图像、宣教短片、PDF/OCR 资源和运行程序，无需另装 Node.js。
• 从桌面或开始菜单打开，在默认浏览器中使用。服务仅监听本机 127.0.0.1:4196，不向院内网络开放。
• 外部教学视频、在线音乐与参考网页需要联网。
• 本机资料按页面保存选项处理，不自动上传或跨设备同步。医护确认是本机操作记录，不能代替医院身份认证。

安装前请确认此电脑为 Windows 10/11 x64，并符合医院信息科的安装策略。Windows 7、32 位 Windows、macOS 和国产 Linux 系统不能使用此包。

需要卸载时，使用 Windows 设置中的应用卸载入口。浏览器健康记录不会随程序卸载自动清除；请在卸载前按需要关闭本机保存并清空资料。

详细说明与第三方许可随程序提供。
