## 2. 康复内容的产品结构

依据 GOLD 与 ATS，将流程组织为“评估 → 确认方案 → 训练与教育 → 记录反应 → 同协议复评”。核心项目应覆盖全身有氧／间歇运动、抗阻、疾病教育与持续行为支持；呼吸肌训练为选择性辅助。GOLD 描述常用 6–8 周项目、至少每周 2 次监督训练，所有剂量仍须个体化。需同时关注功能、症状、目标与依从性，而非只展示肺功能或动画分数。

建议的页面与内容映射属于产品设计规则：

| 模块 | 面向患者的操作 | 临床记录与限制 |
| --- | --- | --- |
| 我的目标 | 选择希望改善的日常活动，如出门、穿衣、平地步行 | 保留患者自定目标；不把“肺年龄”作为康复效果主指标 |
| 入组评估 | 先填疾病、近期变化、活动困难；专业检查可后补 | 记录疾病阶段、合并症、跌倒风险、营养与心理支持需要；缺失数据不当作正常 |
| 今日训练 | 展示已确认的一组训练及休息节奏 | 有氧、抗阻、呼吸肌、廓清分别记录方式／剂量／频次；不因有某台设备就默认全部项目适用 |
| 训练反应 | 训练前、必要时训练中、结束后分别记录症状与测量 | 时间点、Borg 气促／疲劳、心率、SpO₂、氧疗状态、完成量及异常原因；手填值明确标识 |
| 学习与自管 | 短视频、吸入装置示教、行动计划、戒烟与营养支持 | 具体疾病内容分别维护；音乐、冥想是参与和舒适支持，不当作全身运动或 IMT 的等量替代 |
| 复评 | 展示同类指标变化与个人目标完成情况 | 相同方法、单位与条件才可比较；保留质量与上下文，避免用单次变化自动判定疗效 |

急性加重后的 COPD 不应被永久排除。完成医疗稳定性、危险信号及监督条件评估后，可转入专业人员确认的康复路径。ATS 的住院后推荐不等于所有急性不稳定患者可自行高负荷训练，也不支持产品任意设置统一等待天数。

## 3. 呼吸肌与膈肌检查不能互换

依据 ERS 2019 的方法区分：MIP／MEP 反映总体吸／呼气肌压力输出，依赖配合与技术；SNIP 是鼻吸气压力测试，受鼻腔与气道情况影响。膈肌厚度、增厚率、移动度是不同的超声指标，不等同口腔压力或设备阻力。单个低值或单个超声切点不能自动诊断膈肌无力。

以下字段为保持可解释性而制定的产品规则：

| 检查 | 保存的最小信息 | 不允许的自动推导 |
| --- | --- | --- |
| MIP／PImax、MEP／PEmax | 数值及原始符号、单位、日期、设备型号、静态／动态、峰值／持续值、起始肺容积／体位、有效次数、重复性与质量、执行者／审核状态 | 将小鲲动态压力或未说明协议的读数直接等同标准静态口腔压力；由低值直接开具训练 |
| SNIP | 数值、单位、鼻侧、鼻腔通畅情况、测试动作、质量与协议 | 用 SNIP 代替 MIP 计算百分比负荷，或把“鼻吸”当作阻力训练 |
| 膈肌厚度 | 左／右侧、mm、呼吸相位、体位、探头／模式、图像质量 | 由厚度直接换算肌力或推断吸氧量 |
| 膈肌增厚率 | 左／右侧、吸／呼气末厚度与单位、计算方法、动作、体位 | 混淆增厚率和吸／呼厚度比；据单次结果给出确定诊断 |
| 膈肌移动度 | 左／右侧、mm 或 cm、平静／深吸／嗅吸动作、体位、B／M 模式、质量 | 将不同动作或不同单位连成同一疗效趋势 |
| 6 分钟步行／坐站测试 | 具体协议、日期、距离或次数、氧疗／助行器、症状及生理反应、质量 | 将 1 分钟坐站与 30 秒坐站混比；将手机步数当作标准 6MWD |

MIP 或膈肌资料缺失应阻断依赖该资料的解释／负荷处方；不应因此关闭全部已获确认的全身训练、教育与支持项目。参考值必须标明采用的预测方程与人群；无法确认方程时不伪造预计值百分比。

## 4. IMT 适用与负荷边界

GOLD 2026 支持 IMT 能增加吸气肌力，同时指出其叠加于综合肺康复时，对运动能力、气促和生活质量的额外改善并不一致。应由专业评估确定谁需要 IMT，而不是所有患者完成动画后自动升级设备阻力。

产品可实施的确认条件：

1. 记录适应性评估、质量可接受的参考检查及实际使用器械。
2. 分别保存“处方依据”和“实际设备设置”，例如负荷及单位、设备档位、次数／组、组数、频次、休息与复评日期。
3. 如果使用百分比 MIP，显示引用的是哪次有效 MIP、何种协议和医护确认；不能由厂家星级或档位自行换算 cmH₂O。
4. 允许专业人员记录耐受性与复评后的调整；不能按连续打卡、游戏奖励或年龄单独自动加负荷。
5. 不把历史研究中的 30% MIP、30 次呼吸或每天两次组合成所有患者通用处方；不同负荷机制和设备不可直接套用。

以上为保守产品控制，不宣称这些字段本身已构成获批医疗算法或指南规定的固定处方模板。

## 6. 个体化监测的可上线边界

下列为产品安全与数据规则，并非指南逐项规定的统一阈值：

- 每次训练保存方案版本、确认日期、执行项目与实际完成量；开始前检查当日危险信号。
- SpO₂、心率、Borg 等按医护给定的个人监测界限判断；没有个人界限时显示“待确认”，不得悄悄套用正常值并显示安全。
- 新发胸痛、晕厥／濒晕厥、明显静息气促加重等危险信号优先处理；正常单个血氧读数不能覆盖这些信号。
- 训练中的异常记录触发停止／联系医护的提示，具体氧流量和药物不得由网页自动上调。
- 患者录入、设备导出、临床测量、示例数据必须分别标明来源；未知值不画成 0，也不伪造连续监测。
- 静态网页本地记录不等于后台远程监护、电子病历、跨设备同步或具有鉴权的医生签名；“专业确认”表示记录了确认事项，不表示系统核验了医护身份。
- 导出与上传分别由用户触发；公开仓库和部署文件不得包含患者记录、原始报告或可识别信息。
