# 中国大陆吸入装置产品核对记录

查证日期：2026-10-19。用于吸入器教学目录的产品识别与来源追踪，不提供选药或个体剂量建议。

## 核对边界

本记录核对了 27 个具体产品、装置或附件入口。它们包含共用平台上的不同药品，不等于 27 种完全不同的吸入原理。证据来自中国厂商现行产品页、商业上市公告、国家医保局公开申报材料、政府医保与采购公示、国内医院的实际教学资料。厂商商业声明与药品批准信息分别记录；批准、医保纳入、挂网和当日现货也分别理解。

本轮没有完成国家药监局动态药品数据库中每个批准文号及所有再注册、撤市、停产记录的全量核查，也不能看到全国所有药房当天库存。因此目录采用“已核对中国大陆产品资料”，不宣称“中国大陆目前所有可购型号已经穷尽”。没有具体产品证据的海外装置不会因海外有视频而被标为大陆在售。

“产品已核对”和“该器具的完整操作及视频已核对”是两项独立状态。国产仿制品只有成分相同，不能据此推定按钮、装药、计数、试喷或清洁方式相同。找不到完整专用操作说明时保留该产品入口并标出缺口，不编写仿照其他器具的步骤。

本轮都保确认范围限于信必可都保；阿斯利康中国现行产品页中的普米克令舒为雾化混悬液，博利康尼为特布他林片或雾化溶液，不能作为其他都保药品现售证明。易纳器确认全再乐与欧乐欣，比斯海乐确认杰润、恩明润、恩卓润；万瑞舒、昂润、希润的历史或平台资料不扩展为本轮当前产品确认。未纳入本轮确认不等于认定产品停售。

## 操作依据与避免跨装置误用

基本教育流程采用国内原刊的识别、准备、装药、远离吸嘴呼气、密合含嘴、按装置要求吸入、舒适屏气、关闭及回示核验。该 [2019 年国内原刊共识](https://seleguide.yiigle.com/uploads/guide_html/%E7%A8%B3%E5%AE%9A%E6%9C%9F%E6%85%A2%E6%80%A7%E6%B0%94%E9%81%93%E7%96%BE%E7%97%85%E5%90%B8%E5%85%A5%E8%A3%85%E7%BD%AE%E8%A7%84%E8%8C%83%E5%BA%94%E7%94%A8%E4%B8%AD%E5%9B%BD%E4%B8%93%E5%AE%B6%E5%85%B1%E8%AF%86.html) 仅作为既有装置教学原理来源，不能当作 2026 年上市产品清单，也不能代替新型器具的专用说明。

对 Genuair、NEXThaler、HandiHaler 和 Breezhaler 的特别动作，另核对厂商向 emc 提供的正式装置说明：[Genuair](https://www.medicines.org.uk/emc/product/14790/smpc)、[NEXThaler](https://www.medicines.org.uk/emc/product/3317/pil)、[HandiHaler](https://www.medicines.org.uk/emc/medicine/10039)、[Breezhaler](https://www.medicines.org.uk/emc/product/3496/smpc)。它们是海外正式版本，仅用于辨认器具结构和操作原理；不引入海外药物剂量、适应症、盒内吸数或保存期限，最终以患者手中大陆盒内说明书为准。

### 新增国产器具专用说明书核对

平适官方 PDF 为 2 页扫描件，已下载至不发布的质检目录并渲染、逐图读取第 2 页“粉雾剂给药器具说明书”，确认品牌希好、型号 DPI-C3。准备时打开防尘罩和吸嘴，将临用取出的胶囊放进中央药室，合上吸嘴；嘴端朝上，按钮完全按下一次后松开，远离吸嘴呼气，再密合深吸至胶囊振动，检查剩粉并按说明完成同一胶囊的吸入。每使用 10 次清洗，使用前充分干燥；不推定天晴速乐视频中器具一定为相同型号。

吉舒厂商提供完整 HTML 说明书，已读取“气雾剂使用方法”和“清洗”部分。其操作包括取盖充分振摇、含嘴、开始吸气同时揿压并缓慢深吸、舒适屏气、用后漱口。清洗须先拆下药罐，塑料外壳至少每周温水清洗并晾干后装回；没有把其他品牌的固定试喷次数添加到本品教学。厂商产品页含视频播放器入口，链接与播放状态另在视频登记中记录。

其余新增国产产品本轮还存在具体缺口：健可畅、舒稳乐、仙定、彼多益、弘明瑞、硫沙、丙倍、悉立妥的完整现行器具说明书尚未取得或尚未核全。已实际读取厂家产品页与可见附件入口，并检查舒稳乐及新增进口环索奈德的国家医保局公开 PDF；PDF 只列出说明书附件文件名，没有实际下载链接。京卫页脚 JPG 是互联网药品信息服务资格证书，不是吸入器使用图，未作为操作证据。对于这些条目，市场资料确认与完整教学状态继续分别显示。

以下约束贯穿教学数据：

- pMDI 和 SMI 一般需慢而深吸；DPI 按专用器具要求吸入。不能用同一句“越快越好”指导所有类型。
- 胶囊只能放在指定药室，不能吞、不能直接塞吸嘴，也不能跨品牌换器具。刺破后先松开按钮，吸后检查是否按说明完成。
- 药物含 ICS 时显示漱口并吐出的残留预防提示；不含 ICS 的产品不标“激素残留”。面罩雾化后清洁面部是另一项护理。
- 摇动并非全部气雾剂或全部干粉的统一规则；首次启动、停用后复喷、清洁是否能水洗及晾干时间都必须依据对应产品说明。
- 对向装置呼气、堵气孔、按住刺破按钮吸入、反复装药等具体错误采用器具匹配提示，不在不同器具间泛化。
- 不凭“没味道”“没看到雾”就建议额外补药；剂量异常、不会使用或症状未缓解时按个人处方与行动计划联系医护。

应用使用 inhaler-market.mjs 的逐入口来源及查证状态。独立机器清单保存在本地质检目录 .qa/inhaler-expansion/evidence/registry.json，包含已确认与待核实项；普通 HTTP 取得的原始公开文件、SHA-256、解析页码及访问结果记在同目录 fetch-results.json。该质检目录不随公开网页或源代码包发布。
