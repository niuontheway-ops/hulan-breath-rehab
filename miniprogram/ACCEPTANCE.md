## 尚未验证与上线步骤

当前工程使用 `touristappid` 占位，没有注册或绑定正式 AppID，没有向微信平台上传、设置体验版或提交审核，也没有正式小程序码。这里的官方编译与模拟 API 检查，不能替代微信开发者工具及手机客户端验收。

绑定运营方自己的 AppID 后，至少完成以下实际检查：

1. 用微信开发者工具导入工程，核对主体、类目、隐私声明与分包加载，保持合法域名校验开启。
2. 在微信 Android 与 iOS 客户端测试 320px 及常见屏幕、大字模式、原生选择器、视频字幕、后台暂停、每轮主动确认及触屏可达性。
3. 使用合成记录测试重开后本机保存、空间不足、相册/文件隐私授权拒绝、清除后返回旧页面与重新启动。
4. 初次联网载入教学分包后检查本地播放；模拟分包或本地文件被清理后的提示。为音乐配置合法域名，再核对实际播放与使用授权。
5. 由负责医护核对患者引导与现有流程，再按微信平台要求设置体验或提交审核。

工程可以直接导入进行开发；患者通过微信搜索或扫码使用，需要完成上述账号与平台发布步骤。没有承诺断网首次安装、永久本机保存、微信审核通过或临床效果。
