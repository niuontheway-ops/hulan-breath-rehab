# 壶兰呼吸

慢性气道疾病患者的健康评估与互动呼吸康复网页。延续[原应用](https://niuontheway-ops.github.io/human-breath/)的品牌名称与青绿色视觉，并保留原版练习与科普入口。

## 功能

- **报告导入与核对**：JPG、PNG、WebP 本机中英文 OCR；PDF 内嵌文字提取与扫描页 OCR；TXT、JSON 或粘贴文字。保留指标的原文证据，用户明确核对后才填入评估表。区分 FEV₁ 实测升数、预计值百分比、FEV₁/FVC 百分数，以及 MRC / mMRC 原分。
- **个体化康复教育建议**：结合医护确认的病种、年龄、肺功能、静息血氧、呼吸困难评分、ACT / CAT、近期稳定性、医护允许与康复目标分流。展示调整理由、起步内容、频率和参考来源。风险状态关闭自主训练；修改中的评估不能沿用原安全方案。
- **互动呼吸花园**：轻柔鼻吸约 2 秒、舒缓呼气约 4 秒；每一轮计时结束后自主确认，再开始下一轮。植物随进度成长，显示鼓励性文字；可暂停、停止，切到后台自动暂停。朗读默认关闭，仅使用设备本地中文声音，没有本地声音时保留文字。
- **练习记录**：记录自主确认轮数、实际引导阶段用时与练后感受。支持导出建议和记录。模拟患者模式明确标注，退出后恢复原资料；模拟记录不会混入真实资料。

## 运行

环境：Node.js 22 及以上，pnpm。依赖版本固定于 `package.json` 与 `pnpm-lock.yaml`。

```shell
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

浏览器访问 `http://127.0.0.1:4173`。服务器只绑定本机回环地址；可通过 `PORT` 环境变量更换端口。已经构建的交付目录可直接运行 `打开壶兰呼吸.cmd`，无需重新安装网页依赖。

`dist/` 可由任意支持静态文件的 HTTPS 服务托管。脚本、字体资源、PDF 解析器、OCR 引擎和中英文模型均打包到同源目录；运行期间不依赖 CDN。不能直接双击 `index.html` 使用 ES 模块和 OCR，请使用本机 HTTP 服务。初次安装和构建需要依赖下载，构建完成后的本机使用不需要网络。

## 数据处理

报告原始文件、报告文字和文件名仅在浏览器内存中处理，识别结束释放工作线程、画布与内存图像。OCR 不使用 IndexedDB 缓存，不向第三方服务器发送报告。

默认不持久化健康资料。用户主动开启“在这台设备记住评估数值与训练记录”后，只把结构化评估与记录保存在当前浏览器 `localStorage`；这不提供加密、账号隔离、跨设备同步或医护后台。共用设备不宜开启。本机服务不接受 POST，也不接收报告上传。仓库不包含真实患者数据；测试资料均为模拟数据。

## 医学适用范围

本功能面向已获医护评估和允许、状态稳定的成人患者，提供**规则化康复教育建议**。它不能诊断疾病、出具医疗处方、调整药物与氧流量，尚未经临床验证。来源、输入范围、保守产品阈值及使用限制见 [成人康复规则](docs/clinical-rules.md)。指南支持肺康复，不等于验证了本产品的计时、时长或分流规则。

游戏没有呼吸传感器，不测量呼气流量、动作质量或肺功能。记录表示自主确认完成了引导练习，不表示治疗效果。出现胸痛、严重气促、晕厥或咯血时停止训练并寻求医疗帮助。

只录入既有 ACT、CAT 总分，不复制量表题目。MRC 和 mMRC 明确保留类型和原分，不内置未经授权验证的中文问卷。原品牌与原版内容归相应权利人所有；本仓库未复制原版全部网页代码或临床内容。

## 验证

```shell
pnpm test
pnpm check
pnpm exec playwright install chromium
# 在另一终端运行 pnpm start 后执行：
pnpm test:browser
```

单元测试覆盖医学安全分流、量表与日期边界、报告指标解析、文件限制、资源释放、暂停与计时。浏览器验收使用独立临时上下文与模拟报告，验证真实本机图片 OCR、文本 PDF、扫描 PDF、手机布局、人工核对、风险阻断、数据持久化和练习完成。

浏览器测试的第一轮使用真实经过时间；完整 20 轮的集成测试使用受控测试时钟。测试通过不等于临床效果验证。测试生成的文件与截图位于忽略目录 `.qa/`。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `index.html` / `styles.css` | 中文响应式界面与可访问性 |
| `app.mjs` | 评估、核对、方案、训练门控和记录流程 |
| `clinical.mjs` | 可解释的本机教育规则 |
| `reports.mjs` | OCR、PDF 导入、证据与候选值解析 |
| `game.mjs` | 游戏场景、计时、暂停和自主确认 |
| `assets/ocr-lang/` | 本机中英文识别模型 |
| `scripts/` | 构建、本机服务与验收 |
| `tests/` | 全部使用模拟输入的自动测试 |

第三方依赖来源与许可证见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
