# 壶兰呼吸

慢性气道疾病患者的健康评估与互动呼吸康复网页。保留[原应用](https://niuontheway-ops.github.io/human-breath/)的音乐疗法、疾病宣教、日常注意事项和每日评分，使用正式壶兰呼吸 LOGO，并显示莆田学院附属医院呼吸与危重症医学科三区署名。

微信小程序患者端位于 [`miniprogram/`](miniprogram/README.md)，为原生 WXML/WXSS/JavaScript 项目。健康评估、每日评估、训练记录和报告副本只保存在患者手机本地，不使用云开发、账号同步或健康上传接口。保留三种呼吸引导、12 主题宣教、27 项吸入器目录、原有音乐和大字模式。源码可直接导入微信开发者工具；公开体验与正式上线需要运营方的小程序 AppID、隐私声明及微信审核，不把网页二维码当成小程序码。

## 功能

- **医护工作台与患者方案**：专业评估、方案确认、训练监测、同协议复评四步衔接。分别记录 MIP、MEP、SNIP、膈肌移动度／厚度、6 分钟步行和坐站测试，保留原单位、体位、方法、质量与测量协议。
- **个体剂量与监测**：医护明确耐力活动、强度、频次、时长、活动／恢复节奏，按需填写力量与吸气肌训练。IMT 需要可靠 MIP、实际器械适配及原单位负荷范围，不自动计算通用百分比。监测界限由医护填写；缺失读数不能判为正常，越界或新症状立即暂停引导。
- **复评与确认失效**：基线、患者画像或方案改变后重新确认；同单位、同侧别、同体位、同方法、同动作和同协议才计算测量变化。只统计真实结束记录，不用动画得分代替疗效。
- **逐步评估**：每次显示一个问题，从年龄、疾病开始；已有专业评分和肺功能可填写，也可选择“暂时跳过”，材料在后面选填。返回上一步保留已填写信息。缺少必要专业评分时可保存评估，训练需先补充或由医护评估。
- **大字模式**：导航、问题、选项和输入字体同步放大，设置在当前浏览器单独记住；手机窄屏保持单列布局。
- **界面交互反馈**：深墨绿与暖白的临床工作流界面，呼吸机制概念图与明确的下一步操作。选项抬起、按压回弹、步骤切换有节制地反馈；触屏不依赖悬停，减少动态效果时保留静态状态。
- **报告导入与核对**：JPG、PNG、WebP 本机中英文 OCR；PDF 内嵌文字提取与扫描页 OCR；TXT、JSON 或粘贴文字。保留指标的原文证据，用户明确核对后才填入评估表。区分 FEV₁ 实测升数、预计值百分比、FEV₁/FVC 百分数，以及 MRC / mMRC 原分。
- **个体化康复教育建议**：结合病种、年龄、肺功能、静息血氧、呼吸困难评分、ACT / CAT、近期稳定性、医护允许与目标分流。自主呼吸教学与正式医护方案分别管理；较重但稳定的患者可采用院内监督方案，不能仅凭严重程度排除全部肺康复。
- **每日评分与健康评估**：保留 12 个疾病或支持主题，记录当日气促、疲劳、MRC / mMRC、痰液变化、危险症状及选填血氧。可录入已有 ACT / CAT / ESS / FTND 总分和实际完成日期，不复制问卷题目，也不要求每日重做回顾性量表。趋势仅连接实际记录点；同日同主题更新保留其他历史。当日异常和未保存的当日评估关闭训练。
- **疾病宣教与日常注意事项**：12 个主题提供中文神经女声、四段分镜、精细生活场景、镜头运动及短字幕的本地短片。默认显示三条日常行动与求助提醒，完整照护细节及官方资料放在可展开区域。
- **吸入剂教学**：按已核对的大陆产品、装置和储雾罐建立目录，可搜索药名、品牌或装置名；分别显示吸气方式、准备、首次使用、清洁与视频来源。保留原站六项视频作为明确标注的次入口。缺少专属操作或视频的产品单独标记，不套用其他品牌的方法，也不宣称穷尽全国在售批文或实时库存。外部视频需要联网，平台和语言均明示；核查范围见 [大陆吸入器证据](docs/inhaler-mainland-evidence.md)。
- **章节配图**：健康评估、康复计划、训练、每日打卡、宣教、音乐与吸入剂教学，以及十二个疾病主题，使用本地生活场景插画。
- **慢阻肺加重后康复**：区分“仍加重或不稳定”与“加重后已稳定”；后者在医护允许且安全评估通过时可获得轻量分段建议。
- **音乐疗法**：保留安妮的仙境、初雪、迷雾水珠、清晨、童年记忆、雪之梦、月光水岸。支持播放、暂停、停止、音量与进度控制；原版曲目从原站联网加载，也可选择设备音频离线播放。默认不播放，训练配乐需要主动开启，暂停或结束训练时配乐暂停。
- **互动呼吸花园与人物动画**：轻柔鼻吸约 2 秒、舒缓呼气约 4 秒；坐位成人示范的腹部轮廓、双手、连续唇形与气流箭头随同一计时变化，嘴部及腹部放大镜同步展示，并可查看吸气/呼气静帧；提供鼻吸、缩唇呼气和腹部起伏的动作解说。每轮结束后自主确认，再开始下一轮；植物随进度成长并显示鼓励性文字。暂停时人物冻结，切到后台自动暂停；减少动效偏好使用静态示范。朗读默认关闭，仅使用设备本地中文声音。
- **呼吸冥想**：坐位或卧位想象阶梯与草地慢走。阶梯吸气一阶、呼气两阶；草地吸气 2 秒两步、呼气 4 秒四步。场景随引导时钟前进；切换模式先暂停，确认后继续下一轮。只是想象，不要求真实爬楼或行走，不测量实际步数。
- **手机主屏幕入口**：首页提供“添加到手机桌面”，支持浏览器原生安装提示及 Android / iPhone 手动步骤；正式品牌图标、相对路径 manifest 与独立窗口模式用于手机打开。需要患者在自己的手机上主动添加。
- **康复记录**：记录自主确认轮数、实际引导阶段用时、练后感受和每日健康评估。支持导出建议和记录。模拟患者模式明确标注，退出后恢复原资料；模拟记录不会混入真实资料。

## 运行

环境：Node.js 22 及以上，pnpm。依赖版本固定于 `package.json` 与 `pnpm-lock.yaml`。

```shell
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

开发环境访问 `http://127.0.0.1:4173`。服务器只绑定本机回环地址，可通过 `PORT` 环境变量更换端口。

医院电脑使用真正的 Windows x64 EXE 安装向导。将 `hulan-breath-rehab-版本号-windows-x64-setup.exe` 拷到目标医院电脑后安装，可选择位置、桌面及开始菜单入口，并可在 Windows 应用中卸载。程序自带运行时，使用默认浏览器打开，只监听本机 4196 端口；不创建 Windows 服务、开机启动或防火墙规则。兼容范围、未签名说明及联网边界见 [医院安装说明](docs/hospital-installation.md)。

Windows 构建机器先运行 `scripts/installer/prepare-toolchain.ps1` 准备经官方 SHA-256 和 Authenticode 校验的便携 Inno Setup，再运行 `node scripts/package-delivery.mjs`，生成医院 EXE、手机网页 ZIP 和完整源码 ZIP。随包运行时固定为 Windows x64 Node.js v24.19.0（附完整许可证），可通过 `--runtime` 指定；构建流程不会在开发电脑安装本应用或创建系统入口。

手机仍保留独立的主屏幕入口；iPhone 使用 Safari，Android 使用支持主屏幕添加的浏览器，安装须患者主动操作。

在线版本由 `.github/workflows/pages.yml` 发布当前升级分支到 GitHub Pages；扫码地址见 `assets/access-qr.svg`。手机主屏幕入口需要联网加载网页，不自动缓存视频及 OCR 模型。不同浏览器和不同设备的健康记录不会自动互通。

`dist/` 可由支持静态文件的 HTTPS 服务托管。脚本、LOGO、插画、疾病短片、字幕、PDF 解析器、OCR 引擎和中英文模型均打包到同源目录。**7 首原版音乐、吸入剂外部视频和参考资料需要联网**。开发预览使用本机 HTTP 服务，不直接双击 `index.html`；初次安装和构建需要依赖下载。手机添加方法与支持边界见 [手机主屏幕](docs/mobile-home-screen.md)。

## 数据处理

报告原始文件、报告文字和文件名仅在浏览器内存中处理，识别结束释放工作线程、画布与内存图像。OCR 不使用 IndexedDB 缓存，不向第三方服务器发送报告。

默认不持久化健康资料。用户主动开启本机保存后，只把白名单结构化健康画像、专业测量、方案、每日评估及训练记录保存在当前浏览器 `localStorage`；这不提供加密、账号隔离、跨设备同步、医护身份认证或远程监护。真实资料与示例分开，导入备份也不能沿用不匹配画像的确认。共用设备不宜开启。本机服务不接受 POST，也不接收报告上传。仓库不包含真实患者数据；测试资料均为合成数据。

音乐不自动预加载。原版音频请求仅在主动播放或主动开启训练配乐后发往原站，不携带健康记录；设备音频通过临时 Blob URL 播放，文件和文件名不保存，替换或销毁播放器时释放 URL。

## 医学适用范围

本功能面向已获医护评估和允许、状态稳定或加重后已稳定的成人患者，提供康复教育及医护人工确认方案的本机记录与执行辅助。它不能自动诊断、独立开具处方、调整药物与氧流量，尚未经临床验证。最新证据核查见 [指南与设备边界](docs/rehab-evidence-2026.md)，旧自主教学的保守分流范围见 [成人康复规则](docs/clinical-rules.md)。指南支持肺康复，不等于验证了本产品的计时或分流规则。

呼吸训练器、呼吸肌仪和膈肌检查目前采用手工录入。具体型号、报告字段、通信协议和厂商授权接口未核实前，不提供网页蓝牙直连或设备自动调阻。本机“医护确认”只是明确的操作声明，不能证明操作人资质；正式临床部署仍需实际设备核对、医护审核及本地管理流程。

游戏没有呼吸传感器，不测量呼气流量、动作质量或肺功能。记录表示自主确认完成了引导练习，不表示治疗效果。出现胸痛、严重气促、晕厥或咯血时停止训练并寻求医疗帮助。

只录入既有 ACT、CAT、ESS、FTND 总分，不复制量表题目。MRC 和 mMRC 明确保留类型和原分，简明中文提示注明来源、改写与验证限制。原品牌、音乐和原版内容归相应权利人所有；音乐使用范围见 [第三方资源](THIRD_PARTY_NOTICES.md)。

## 验证

```shell
pnpm test
pnpm check
pnpm exec playwright install chromium
# 在另一终端运行 pnpm start 后执行：
pnpm test:browser
```

单元测试覆盖医学安全分流、每日记录校验与更新、量表与日期边界、疾病宣教覆盖、报告指标解析、文件限制、播放器控制与资源释放、人物动画同步、暂停与计时。浏览器验收使用独立临时上下文与模拟报告，验证真实本机图片 OCR、文本 PDF、扫描 PDF、手机布局、人工核对、风险阻断、数据持久化、每日评分、全部宣教主题、实际音频播放和人物动作。

浏览器测试的第一轮使用真实经过时间；完整 20 轮的集成测试使用受控测试时钟。测试通过不等于临床效果验证。测试生成的文件与截图位于忽略目录 `.qa/`。

音乐验收读取原站实际 MP3，需要联网；如测试环境需要 HTTP 代理，可设置 `HULAN_MUSIC_TEST_PROXY`。其他浏览器验收均使用本机资源及临时模拟资料，不接入用户的浏览器会话。
