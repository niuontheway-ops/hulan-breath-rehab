## 本次检查不能证明的事项

- 未进行患者真机试用、临床有效性研究、独立临床审核或设计奖评审。
- 未连接实际呼吸训练器、呼吸肌力仪或膈肌设备；型号、输出字段与接口仍须对照实物和说明书核对。
- 网页只检查已手工输入的数值，不能发现未录入的异常，也不能代替持续监护、设备压力控制或真实现场监督。
- 本机确认没有医护身份认证，不是医院多患者管理系统。当前适合作为受控演示、操作核对及本机试用候选；临床启用应另完成实际设备和本地管理流程审核。

所有剂量由实际医护填写并确认；测试中的数值不作为患者默认处方。指南来源与产品规则明确分开，见[证据核查](rehab-evidence-2026.md)。
