## 与现有条件的适配

设备入口明确标注手工录入和未直连。呼吸肌力记录先保存原单位及质量；计划中的 IMT 必须关联已核对的 MIP，并由医护核对实际设备型号、单位和负荷范围。没有 MIP 不启用 IMT，但不因此取消全部肺康复。

膈肌记录保存实际方法、侧别、体位、呼吸动作和协议。复评只比较条件完全一致的指标，不用单个超声数值直接诊断肌无力或生成训练强度。6 分钟步行和坐站记录用于医护制定、复评全身运动方案，不自动映射固定处方。

训练前、中、后分别记录，不把三个监测点统计成三次完成。计时器展示方案的活动和恢复节奏；记录缺失、越界、不适或离开页面时暂停。网页不能实时感知患者、读取呼吸压力、调整装置或代替现场监督。

## 设计方法

实际使用个人美学规则、frontend-design、finesse-ui 和 gsap-web-motion 的信息层级、触控反馈与节制动效方法；动效采用现有 CSS 与浏览器动画时钟。具体来源规则与视觉验收见[设计记录](rehab-design-direction.md)。概念图均有明确示意标签；正式品牌图原样保留。没有参赛或获奖结果。

## 验收边界

自动测试、浏览器操作、布局截图和本机启动检验可以证明特定软件行为，不能证明临床疗效、真实患者可用性、实际硬件适配或医护审核已完成。正式患者部署前需要在实际设备与本地临床流程中核对。
