# 呼吸动作动态示范

人物演示由本地 SVG 与训练的单调时钟共同驱动，无远程库、麦克风或摄像头。演示动作不测量患者呼吸，不推断肺功能改善。腹部训练须由医护确认适合；画面起伏为辨识而适度放大，不是患者必须达到的幅度。

## 画面与动作

- 成人侧坐，椅背支撑，双脚着地。皮肤、头发、衣料和椅子分别使用局部渐变；保留项目绿色与暖肤色。
- 一手轻放胸部，一手轻放腹部。肩与肘保持固定，前臂曲线连接变化的手部目标，避免整条手臂平移造成关节断开。
- 鼻吸时腹部轮廓自然向外，腹部手随动；缓慢呼气时轮廓和手回落。胸部只呈小幅自然起伏。
- 嘴唇在呼气初段由放松到收拢，局部嘴部与腹部放大镜使用相同的呼吸进度，气流箭头显示鼻吸和缩唇呼气方向。
- 暂停保留实际阶段剩余时间与姿势；停止保留身体姿势并清除气流。页面隐藏时暂停，返回后须主动继续；退出时移除帧循环和监听。

“吸气静帧”和“呼气静帧”仅查看动作。训练正在运行时先暂停；“跟随节奏”回到当前真实暂停姿势，不自动恢复计时。系统要求减少动效时不连续改变人体轮廓，可按静帧按钮主动比较两种姿势。完成一轮仍须患者自行确认，花园只根据确认轮数生长。

## 视觉方法

采用用户级 `personal-aesthetic-design` 的基础模板 T006（局部修正），以及来源规则 R001、R002、R003：统一人物与环境的形体/光向，保留可辨的头发、衣服、手指，并把绿色环境、肤色主体和动作箭头分别分配视觉角色。核对来源笔记 W177、W178、W172。人体动作与网页应用属于独立设计和几何实现，不归为来源作者教授的临床或交互方法。

按 R010 与基础 B001–B004 对照实际输出：检查动作、阶段、停止状态、键盘、窄屏和大字；完成证据属于模型检查和软件验证，不代表患者理解率或独立临床审核。SVG 编辑使用 `svg-editor`，保留可编辑路径、唯一实例 ID、局部渐变和标题描述。
