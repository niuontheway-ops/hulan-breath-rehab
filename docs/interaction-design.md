# 界面层次与交互反馈

## 目标与基线

版本 1.2.0 在逐步评估及原有康复功能上增加选中、按下、悬停和步骤切换反馈。基线是 1.1.0；检查使用同一视口、同一问题和模拟输入。视觉变化不代表临床效果或经过老年患者可用性研究。

## 美学依据

实际读取 `personal-aesthetic-design` 0.2.0、知识状态、来源规则、基础规则、来源笔记和应用证据。采用基础模板 `templates.md/T006` 局部视觉修正；主视觉采用 `source-templates.md/T001` 的同材质构图变量。

- R001 / W179、W177：花园元素统一圆润形体、青绿材质与光向。
- R004 / W167：明暗与边界区分图形和可操作表面；控件阴影、按下回落及选中抬起为独立 UI 迁移。
- R005 / W177：以近景幼苗、中景山体和后景日光组织主视觉空间，不把插画解释为真实医学结构。
- R009 / W174：冷青绿环境与少量暖光支持平静、愿意开始的视觉语气；未据模型自检证明真实情绪或康复效果。
- B001–B003 / R010：保留文字对比、窄屏重排、原生输入、可见焦点与非颜色状态提示；以实际结果核验，不能只用“立体”“弹性”等描述代替作品。

## GitHub 学习与实现选择

参考 [Motion 官方 GitHub 项目](https://github.com/motiondivision/motion)及 [animate](https://motion.dev/docs/animate)、[hover](https://motion.dev/docs/hover)、[press](https://motion.dev/docs/press) 文档。实际采用的是动作与反馈组织方法：短暂按下、松开回弹、选择后保持状态、鼠标悬停与触屏区分。没有复制项目源码，没有安装全局运行库或 MCP。

当前页面使用原生 CSS 过渡与 Web Animations API，不引入 React 或外部脚本。平移、缩放、透明度和有限阴影提供反馈；不使用持续晃动、滚动劫持或自动推进问题。原生单选框、复选框和下拉框保留其键盘、校验与数据行为。

## 行为参数

| 状态 | 实现 |
| --- | --- |
| 选中 | 桌面上移 5 px、放大至 1.022；手机上移 4 px、放大至 1.014，强化阴影与勾选图形 |
| 按下 | 下移 2 px、缩小至 0.98；松开后回到正常或选中位置 |
| 悬停 | 仅在支持悬停且精确指针的设备上出现；触屏依赖实际选择反馈 |
| 步骤切换 | 用户前进或返回后，当前问题 220 ms 轻移入场；不延迟操作或改变填写顺序 |
| 下拉选择 | 选值后保留浅绿底与边框，短暂外圈反馈；选项弹层由浏览器提供 |
| 减少动态效果 | 关闭位移、缩放与入场动画，保留勾选、边框、底色与文字状态 |
| 后台/中断 | 取消装饰动画与按下状态；训练计时及人体动作继续由原游戏逻辑负责 |

## 检查

实际结果、前后截图与交互录像位于本机忽略目录 `.qa/motion/`。216 项现有单元测试和 25 条逐步评估流程通过；交互专项 20 条流程通过，覆盖选择状态、鼠标/触屏/键盘、快速重复选择、返回保留、320/390 px 普通与大字模式，以及减少动态效果，无脚本错误或默认外部请求。鼠标实际选中矩阵为 `scale(1.022)` / `translateY(-5px)`，按下为 `scale(.98)` / `translateY(2px)`；触控为 `scale(1.014)` / `translateY(-4px)`。检查发现插画字幕沿用旧深底，已修正为浅底深字；触屏按下状态由指针事件清理，避免模拟 `:active` 状态滞留。修正后另完成 4 条受影响交互与 6 个首页视口/字号检查，字幕合成背景对比为 9.51:1。录屏及由实际录屏编码的 GIF 展示真实点击反馈。未开展实体手机、Safari 或老年患者测试。
