# 章节与疾病宣教插画

`assets/chapters/` 包含 19 张独立 SVG，均采用 `viewBox="0 0 640 360"`。图形由本地矢量源绘制，不依赖远程图片、字体、脚本或图像生成接口；正式品牌 LOGO 不在这些文件中重绘。

插画用于章节识别和健康教育概念表达，没有患者资料、诊断数值、病情程度或数据映射。吸入器、检查设备、呼吸面罩和心肺符号均为概念形体，不作为药品产品图、实际检查结果、医学解剖或操作步骤的依据。具体教学依照相邻的正文、视频及其医学来源。

## 视觉方法

实际读取并采用 `personal-aesthetic-design` 0.2.0：R001 统一曲率和材质观感；R002 保留长者、医护与主要物件的识别特征；R003 分配环境青绿、主体深绿和暖杏辅助色；R005 用人物、家具、窗景组织前中后景；R009 以稳定姿态、明亮背景和柔和阴影表达健康教育语气；R010 逐项核对实际输出。

来源核对为 W179、W177、W172、W168、W174、W167 的风格卡观察。系列角色与医疗生活场景是独立矢量设计，不能归因于作者教授了临床插画或整套网页设计。采用 `source-templates.md/T002` 的亲和角色结构和 `T003` 的场景层次组织；未照搬作者提示词或原图。

主要色值：背景 `#f2f8ee` / `#dcecdf`，服装 `#a7d2b7` / `#6aa68b`，轮廓 `#315f55`，暖杏 `#f3d3a7`。这些是本次任务的实际实现值，不是从来源截图中推定的参数。渐变和小范围落影保留适度体积；输出仍是矢量生活场景，不宣称是真实青瓷雕塑或完整三维渲染。

## 验证

- `svg-editor/scripts/validate_svg.py`：19 张 SVG XML、唯一 ID 及内部引用检查全部通过。
- 浏览器在 320×180 实际展示尺寸联排渲染：19/19 成功解码原始 640×360 尺寸，无脚本错误。
- 实际查看联排图后修正桌腿相对坐标、气胸场景的座椅与病床重叠、睡眠图睁眼及面罩辨识问题，并重新渲染查看。
- 图中没有正文、小字标签、药品品牌或虚构病情指标。SVG 的 `title` / `desc` 明确记录概念用途；作为网页装饰图时，页面应根据相邻标题决定是否使用空 `alt`，避免重复朗读。

视觉结果为模型实际查看后的检查，没有实体手机、患者可用性试验或独立临床插画审核。人物动作用于章节识别，不能替代具体训练动作教学。
