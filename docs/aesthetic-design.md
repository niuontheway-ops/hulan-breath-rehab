# 康复应用视觉设计记录

日期：2026-10-10。技能版本：`personal-aesthetic-design 0.2.0`；证据版本：`2026-10-10-wechat-1`。本记录说明具体设计选择与检查边界，不作为医疗效果或老年人可用性研究结论。

## 模板与读取依据

使用 `references/templates.md` 的 **T002 数据与表单应用**：让患者逐步补充已知信息，把当前问题、必要解释、填写控件和下一步操作放在一起。专门量表允许跳过，资料上传安排在基础信息之后；步骤和安全逻辑由应用代码执行，CSS 只呈现状态。

实际读取了技能入口、`knowledge-status.md`、`rules.md`、`learned-rules.md`、`templates.md`，以及被选规则对应的 `source-notes.md` 条目 W175、W174、W172、W169、W176、W170、W160。同时读取 `frontend-design` 技能，检查现有网页和游戏的样式结构。

采用的规则：

- **R003 色彩角色**：将来源材料中的区域色域关系转为本项目的页面、正文、行动和选中状态；色值根据品牌与可读性选定。W175/W174/W172/W169 的图像观察不提供网页控件规范。
- **R006 留白**：将来源中的实际面积核对转为问题之间的间距、单题宽度和窄屏重排。W176/W170/W160 保留正例与未充分实现项；没有照搬“极简”标签。
- **B001**：计算实际前景与背景色的相对亮度对比。
- **B002**：320/390 像素下重排页头、向导按钮、摘要和导航，不整体缩小页面。
- **B003**：保留可见焦点、已选择的边框与单选圆点，错误仍带文字说明；不只依靠颜色区分。
- **B004**：患者当前填写动作优先，首页保留康复、每日评估、宣教、音乐与记录的入口。

其中网页信息架构、文字体系、组件状态及老年模式是本项目的独立迁移设计；不归为作者已讲授的网页方法。T002 为技能中的独立组织基础模板，不是作者原始模板。

## 设计决策

第一遍先确定品牌深绿、白色阅读区、浅绿状态区与有限砂色点缀，并拟定单题向导和大字字号。复核受众后，去掉与填写无关的新增视觉装饰：正式 LOGO 原图、原有花园及人物动画继续使用，填写区以当前问题为重心。原有音乐、宣教、每日评估、训练与历史样式类保持有效。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 行动与品牌 | `#124C46` | 主按钮、已选边框、焦点、关键行动 |
| 页面 | `#F7FAF7` | 全局阅读背景 |
| 内容区 | `#FFFFFF` | 表单与内容卡片 |
| 正文 | `#173C38` | 主要文字 |
| 辅助文字 | `#536D67` | 解释与次要信息 |
| 已选择 | `#E4F0EA` | 选中项、安静提示区 |
| 砂色 | `#F2E8D4` | 示例与有限辅助提示 |

字体使用现有本地中文字体 `Microsoft YaHei`、`PingFang SC` 与系统回退；没有增加外部字体请求。普通模式正文以 16–17 像素为主，向导问题 23–26 像素，选择项 18 像素，关键按钮不少于 48 像素高。大字模式正文及操作 20–22 像素，当前问题 28–30 像素，关键按钮 56–60 像素高。`senior-mode` 在内容层调整字号与间距，没有使用缩放变换。

桌面向导与辅助说明分区；1100 像素以下说明移到向导后方。手机页头将品牌和开关分为两行，避免 LOGO、科室与操作互相挤压；摘要转为单列，返回/跳过与下一步重排。底部导航在大字模式中允许文字两行，主要内容预留固定导航和安全区的高度。游戏动画保留原运行逻辑，大字模式只放大界面外部说明与操作，不更改示范动作或宣称测量了真实呼吸。

## 实际色彩计算

采用 sRGB 线性化、相对亮度与 `(较亮亮度 + 0.05) / (较暗亮度 + 0.05)` 计算。结果为实际 CSS 色值对比，未包含原图内部文字、半透明图片叠层及所有动态状态。

| 实际颜色组合 | 对比值 |
| --- | ---: |
| 正文 `#173C38` / 页面 `#F7FAF7` | 11.48:1 |
| 辅助文字 `#536D67` / 页面 `#F7FAF7` | 5.32:1 |
| 正文 `#173C38` / 白卡 | 12.07:1 |
| 辅助文字 `#536D67` / 白卡 | 5.60:1 |
| 白字 / 深绿主按钮 | 9.78:1 |
| 深绿文字 / 浅绿已选项 | 8.36:1 |
| 提示文字 `#775421` / 砂色 `#F2E8D4` | 5.62:1 |
| 占位提示 `#61776F` / 白色 | 4.80:1 |
| 表单边框 `#738E82` / 白色 | 3.55:1 |
| 深绿焦点线 / 近白页面 | 9.30:1 |

上述正文组合均达到 B001 所引用的常规文字 4.5:1 检查值；表单边框另按非文字可辨性计算。卡片装饰分隔线不承担控件辨识。

## 验证边界

本记录已完成参考读取、样式实现与上述色值计算。最终 HTML 的 320/390/1440 像素布局、普通/大字模式、单题切换、跳过与返回、校验反馈及键盘焦点已通过 25 条实际浏览器流程；另有 18 条保留功能流程检查音乐、宣教、每日评估和游戏。截图复核发现疾病选项受旧嵌套样式影响偏小，已修正并重新验证选项实际字号；大字手机视图减少重复辅助说明。机器结果和截图保存在本机忽略目录 `.qa/`。未开展老年患者人工使用测试；不提供美观提升百分比或医学效果推断。
