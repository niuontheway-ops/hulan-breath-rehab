# 呼吸康复界面设计

日期：2026-10-18。

## 目标与范围

界面首先解释患者下一步应该做什么，并使医护能核对测量条件、方案剂量、训练监测和复评依据。设计质量以实际页面的阅读顺序、关键状态、交互完成和窄屏可用性验收。国际设计奖项作为设计追求；本项目没有参赛、获奖或外部评审结果。

保留壶兰呼吸正式 LOGO、医院和科室名称、大字模式、逐题健康评估、每日评估、音乐、宣教、吸入剂教学及现有训练示范。品牌原图仅按比例显示，不重绘。

## 当前基线的问题

原界面采用大量等权、浮起的圆角卡片。盆景主图与实际呼吸功能评估关系较弱，患者容易把全套肺康复理解为跟随呼吸的小练习。首页安装入口一度占据首屏主要空间。已有内容被并排展示，缺少评估、制定方案、训练和复评的连续关系。

## 视觉与信息顺序

采用临床工作流，而非宣传型着陆页。深墨绿色导航形成稳定边界，暖白内容区承载录入与阅读；一个主动作指向当前任务。患者首页先展示健康画像和主要行动，随后呈现四步路径、真实方案状态及支持工具。手机安装帮助排到辅助区域，点击后再展开具体步骤。

医护工作台以四步组织：专业评估、方案确认、训练监测、复评调整。真实缺失显示待补充，不以零值或装饰性波形填空。方案、读数、设备档位和压力单位必须有文字标签；颜色不单独承担临床状态。训练示范和放松内容不被包装成设备实测或疗效数据。

| 名称与色值 | 用途 |
|---|---|
| Mineral `#eef2f0` | 页面底色，与临床阅读表面分层 |
| Cloud `#fcfdfb` | 表单、记录与阅读表面 |
| Evergreen `#123f3a` | 正式品牌延伸、主要行动、当前步骤 |
| Carbon green `#142d29` | 标题、数值和正文 |
| Graphite `#4d625b` | 可读的辅助说明 |
| Amber `#77521b` / `#f8efd8` | 待核对事项，始终配文字 |
| Red `#a33538` / `#faedeb` | 危险或停止状态，始终配操作说明 |
| Blue `#245c72` / `#e6f0f3` | 记录或就绪状态，与品牌色区分 |

字体使用本地高可读中文无衬线字体，不依赖外部字体下载。中文标题保留足够行距；临床数据使用等宽数字。患者正文和主要操作不采用装饰性衬线字体。表单标签在输入框上方，单位持续可见。

不采用相同圆角和阴影套用所有区域：导航、流程分隔线、主要康复方案、普通记录、输入控件各有边界层级。主要内容无需滚动触发动画才可见。

## 实际采用的方法与来源边界

- `frontend-design`：先按呼吸康复任务决定布局与信息优先级，再建立色彩、文字与空间规则；审查无关主视觉、等权卡片和模板化装饰。
- `finesse-ui`：实际读取 redesign-mode、design-dna、product-ui、product-palettes、mobile-floor、workflow-ui、preflight 参考；查看其 ACRU light dashboard 示例代码，仅借鉴深色导航与浅色内容的边界、主工作区与摘要分区，不复制演示数据或页面。依照产品/工作流语境，未添加品牌宣传页的噪点、暗角、巨大标题或 3D 装饰。
- `gsap-web-motion`：实际读取入口、已核实纠正和性能参考。当前反馈用既有 CSS、原生计时与 SVG 即可完成，没有因技能名称额外加入 GSAP 运行库。选择项向上移动 2 px 并显示勾选，按下反馈缩小至 0.99；减少动效模式保留完整静态选中态。没有滚动劫持、循环漂浮、自动数值递增或装饰波形。
- `personal-aesthetic-design`：实际读取知识状态、基础规则、来源规则与所选来源笔记。使用 B001–B004（对比、重排、操作状态、内容主次），R003/W175（区域与颜色角色）、R006/W160（按实际面积检查留白）、R008/W165（图形外观不代替数据）、R010/W160/W165（目标与实际输出核对）。来源卡面仅支持图像层面的观察；本界面的工作流、组件系统和 UI 迁移为独立设计判断，并非来源作者已提供的医学产品规范。

未声称完整观看目标账号全部视频，也不将界面自检描述为用户测试、外部专家审核或临床有效性验证。

## 验收证据

源代码临时预览只绑定本机环回地址，使用隔离浏览器上下文，不读取浏览器个人资料或患者附件。截图和检查结果保存于本地 `.qa/clinical-design/`，不随公开源码发布。

首轮样式检查覆盖 1440、768、414、375、320 CSS px 的普通和大字模式。实际截图发现手机导航继承桌面宽度、安装入口层级过高、旧版大字页头纵向堆叠三个问题，已分别重置手机导航宽度、压缩并后置安装帮助、修正页头重排。整合检查覆盖首页与专业评估的上述十种布局，并检查 1440 普通模式与 320 大字模式下的方案、监测和复评，共 26 个页面状态；记录中没有根横向溢出、可见内容越界、按钮文字裁切、脚本异常或资源 404。此检查使用空病例与本机浏览器，不能替代功能与医疗规则测试。

截图检查与自动化结果只支持所测浏览器和布局；没有开展实体手机性能测试、老年患者可用性研究或国际奖项评审。

关键前景/背景色计算对比：正文 14.32:1，辅助正文 6.40:1，页面辅助文字 5.79:1，主按钮 11.45:1，导航辅助文字 8.14:1，待核对状态 6.10:1，警示状态 5.88:1，就绪状态 6.36:1。静态检测器对新设计样式未报告 findings；两个 SVG 通过 XML 结构验证。结构检测不证明视觉质量或医学准确性。
