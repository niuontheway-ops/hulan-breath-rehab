# 医院电脑安装入口

当前 Windows 交付采用 EXE 安装向导，具体步骤、兼容系统、卸载和数据边界见 [医院安装说明](hospital-installation.md)。

运行 `node scripts/package-delivery.mjs` 生成医院安装 EXE、网页发布 ZIP 和完整源码 ZIP。EXE 包含网页、原有本地疾病短片、OCR/PDF 资源及 Windows x64 Node.js v24.19.0，不要求医院电脑安装开发依赖。新增吸入装置外部教学视频、原版音乐和参考网页需要联网，不把外部视频下载转载到包内。

旧版本的便携电脑 ZIP 已停止作为当前交付格式。项目中的旧启动及快捷方式脚本保留作源码兼容资料，不作为新版本安装指引；新 EXE 不包含旧的手工安装快捷方式入口。

手机网页和“添加到手机桌面”仍保留，使用方式见 [手机主屏幕](mobile-home-screen.md)。手机与医院电脑的健康记录不会自动同步。
