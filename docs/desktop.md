# Windows 电脑本地运行

电脑包与手机网页分别提供。手机继续使用 HTTPS 网页和“添加到手机桌面”；电脑包在 Windows x64 本机启动 HTTP 服务，再由系统默认浏览器打开康复工作台 `/#clinic`。

## 文件契约

| 位置 | 用途 |
| --- | --- |
| `打开壶兰呼吸.cmd` | 启动本机服务并打开默认浏览器 |
| `停止壶兰呼吸.cmd` | 仅停止与当前电脑包身份相符的本机服务 |
| `安装桌面快捷方式.cmd` | 在当前用户的 Windows 桌面创建专用快捷方式 |
| `runtime/node.exe` | 包内 Windows x64 Node.js v24.19.0，无需预装 Node.js |
| `runtime/LICENSE.txt`、`runtime/runtime-info.json` | 运行时完整许可、版本及 SHA256 |
| `dist/` | 构建后的网页、评估、康复工作台、冥想、手机 manifest 与本地媒体 |
| `scripts/serve.mjs`、`scripts/desktop/` | 本机服务、进程归属核验与快捷方式脚本 |
| `源代码备份/` | 源代码、锁文件、测试、文档及构建脚本 |

## 使用方法

1. 将整个“壶兰呼吸-电脑本地版”解压到固定文件夹，不要从压缩包内运行。
2. 双击“打开壶兰呼吸.cmd”，在默认浏览器打开工作台。
3. 如需从桌面进入，双击“安装桌面快捷方式.cmd”。正式 LOGO 派生图标用于该快捷方式。
4. 关闭浏览器后，本机服务仍可继续运行。结束使用时双击“停止壶兰呼吸.cmd”，或关闭电脑。
5. 更新或移动电脑包前先停止服务，再完整解压并重新安装快捷方式。

脚本只使用包内 `runtime/node.exe`，不会查找个人缓存中的运行时，也不会在线安装依赖。固定服务地址为 `http://127.0.0.1:4196/`，仅监听本机回环地址，不对其他电脑或手机提供服务。

重复打开只复用同一个电脑包的服务。启动与停止均验证应用标识、构建信息 SHA256、健康端点 PID、进程可执行文件和精确服务脚本路径。其他应用、其他文件夹的电脑包或构建信息不一致时拒绝接管；不会自动结束占用端口的未知进程。

## 网络与数据边界

随包的页面、宣教短片、字幕、图像及 PDF／OCR 资源可从本机加载。原版在线音乐、吸入剂外部视频和外部参考网页需要联网；手机网页需正常网络访问。不得将这些外部资源描述为已经离线打包。

健康资料的保留遵循页面中的本机保存选择。电脑本地版、手机网站与不同浏览器之间没有自动同步。设备型号和接口未经确认时，工作台使用手工记录，不提供伪造的蓝牙直连、云端监测或自动医疗处方。

桌面快捷方式只指向电脑包，不复制健康记录。移动文件夹会使旧快捷方式失效，应停止服务后重新创建。没有安装 Windows 系统服务、计划任务或开机启动项。

## 构建与验收

完成 `node scripts/build.mjs` 后，运行 `node scripts/package-delivery.mjs --runtime <Windows-x64-Node-v24.19.0-node.exe>`，产生电脑、网页、源代码三个 ZIP 及哈希清单。未指定 `--runtime` 时只使用运行打包脚本的 Node.js；版本、平台或架构不匹配会拒绝打包。

启动检查可执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/desktop/launch.ps1 -NoBrowser`，成功返回健康端点 JSON。停止检查使用 `stop.ps1 -Quiet`。快捷方式检查可传入 `install-shortcut.ps1 -DestinationDirectory <项目内验证目录>`，无需访问实际桌面。

交付验收应检查：从完整解压包启动、`/#clinic` 可用、重复启动复用、服务身份不符时拒绝接管、停止后端口释放、图标和快捷方式目标正确、断网时本地媒体可读，以及源码与网页构建哈希一致。此文档描述验收条件；具体执行结果另记在验证文档中。
